# React Portfolio Platform

A simple portfolio website built with React and Vite for a Moringa school assignment. It displays sample projects and lets visitors search by project title or description and filter by category.

## Features

- Responsive navigation and page layout
- Project cards with descriptions, categories, and technologies
- Search projects by title or description
- Filter projects by category
- Friendly message when no projects match

## Technologies

- React
- JavaScript
- CSS
- Vite

## Run locally

You need Node.js and npm installed.

1. Install the project dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open the local URL shown in the terminal.

## Other commands

Create a production build:

```bash
npm run build
```

Check the code with ESLint:

```bash
npm run lint
```

## Project data

The sample project information is in `src/data/projects.js`. You can edit the project titles, descriptions, categories, technologies, and links there.
